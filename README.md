# X Video Best Quality & X Pro Enhancement

`X Video Best Quality` 是一款轻量、强大且极简的开源 Chrome Manifest V3 扩展。它专为 **X (Twitter)** 深度打造，不仅能强力锁定最高清晰度视频流与图片原画，更集成了时间线广告净化、纯净短链防追踪与沉浸式播放控制套件。

UI 采用极致黑白纯黑 OLED 极简质感，零杂色、无打扰，纯粹沉浸。

---

## ✨ 核心特性

### 🎬 1. 强制 HLS 原画画质锁定
- **尽早拦截劫持**：在页面主环境尽早 hook `fetch` 和 `XMLHttpRequest`，专一处理 `video.twimg.com` 的 `.m3u8` 请求；
- **智能重写 Master Playlist**：解析并重构多路 variant，按你设定的清晰度上限只保留一路最高可用流；
- **档位随心选**：提供 `最高可用`、`4K / 2160p`、`2K / 1440p`、`1080p`、`720p`、`480p`、`360p`；
- **工具栏角标（Action Badge）**：浏览器扩展图标右上角以醒目的黑白微徽章实时显示当前视频真实分辨率（如 `4K`、`1080`、`720`），停用时显示 `OFF`。

### 📥 2. 原画视频直链复制与一键下载
- **复制 M3U8 直链**：一键提取当前检测到的原画视频直链，直接贴入 IINA、VLC、Downie、Aria2 或 IDM 进行高速下载或外置播放；
- **一键下载流**：点击通过 Chrome Downloads API 直接触发当前流文件保存。

### ⚡ 3. 播放控制套件（画中画 + 倍速记忆）
- **画中画 (PiP)**：弹窗内一键将当前 X 视频弹出为悬浮小窗，边刷信息流边看；
- **跨推文倍速记忆**：支持 `1.0x` / `1.25x` / `1.5x` / `2.0x` 快捷切换，滚动刷到下一个新视频时自动保持你偏好的倍速。

### 📸 4. 推文图片「强制原画」与单张原图直接保存
- **强制加载原图**：自动将配图请求重定向至 `name=orig`，加载相机直出的原画尺寸照片；
- **智能悬浮感知**：平时按钮完全隐形不遮挡画面，只有鼠标移至推文配图或大图右上角时，才平滑浮现「💾 下载此张原图」按钮，点击立即无损保存当前选中的图片（绝不批量下载多余图片）；
- **快捷键**：支持按住 **`Alt + 单击`** 任意推文配图直接保存无损原图。

### 🧹 5. 时间线强力净化
- **拦截广告赞助推文**：毫秒级自动识别并隐藏时间线夹带的 Promoted / 赞助推文，彻底抹平空白占位；
- **侧栏清爽折叠**：自动屏蔽右侧边栏“订阅 Premium”横幅与“推荐关注”打扰。

### 🔗 6. 纯净短链与防追踪复制
- **剥离追踪参数**：复制推文链接时，自动将末尾的追踪小尾巴（如 `?s=20&t=xxxx`）干净剥除；
- **直连绕过 `t.co`**：自动还原推文内的真实目标网址，点击直达秒开，告别跳转等待与隐私追踪。

## 📁 目录结构

```text
x-video-best-quality/
├─ manifest.json     # 扩展清单配置 (Manifest V3)
├─ background.js    # 后台 Service Worker (动态 Badge 角标、下载处理)
├─ bridge.js        # 隔离环境脚本 (DOM 净化、原图增强、短链去追踪、播放控制)
├─ pageHook.js      # 页面主环境脚本 (MAIN World HLS 请求劫持与清晰度重构)
├─ popup.html       # 扩展控制面板 (极简纯黑 OLED 布局)
├─ popup.css        # 样式表 (高级黑白设计、iOS 质感微动效)
├─ popup.js         # 面板交互与状态管理
├─ demo.html        # 本地可视化交互演练工作台
└─ README.md        # 项目说明文档
```

## 🛠️ 安装与使用方法

1. 下载或克隆本项目到本地；
2. 打开 Google Chrome 或 Edge 浏览器，访问 `chrome://extensions`；
3. 打开右上角的 **“开发者模式”**（Developer Mode）；
4. 点击左上角的 **“加载已解压的扩展程序”**（Load unpacked）；
5. 选择包含 `manifest.json` 的 `x-video-best-quality` 文件夹即可完成安装；
6. 打开 [X / Twitter](https://x.com) 即可享受纯净极致的视听体验！
